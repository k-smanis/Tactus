# Architect Initiative

First, discuss an initiative belonging to the current phase with the user until you understand its intended outcome, scope, implementation approach, dependencies, anticipated issues, and required tasks.

Then, crystalize the initiative in `Tactus/Project/Progress/Progress.sqlite` as part of that phase, add its tasks, and associate each task with its relevant files.
