# Recover

First:

- Diagnose what is wrong with the current session, such as polluted context, an impractical approach, poor code quality, or poor organization.

Then

- Suggest a recommended action, and - if starting a new session is relevant - a recovery prompt.
- Do not perform the recommended action unless the user asks.
